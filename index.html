Privacy Policy

Effective date: September 5, 2026

1. Overview

JP_Senior_Uploader ("the Application") is a personal automation tool operated by Minkuk Choi. It uses the YouTube Data API v3 to upload original videos and Shorts created by us to our own YouTube channel, こころの縁側 (kokoro-no-engawa), and to set their metadata (title, description, tags, thumbnail, language) and privacy status.

2. Data we access

The Application accesses data only for our own YouTube channel, using OAuth 2.0 scopes youtube.upload and youtube.force-ssl. The data accessed includes: uploading videos, reading/updating our own video metadata, and setting thumbnails for our own videos. The Application does not access, collect, or process any data of other users, viewers, or third parties.

3. Data storage and retention

OAuth credentials (a refresh token) are stored locally on the operator's own computer and are used solely to authenticate API requests for our own channel. No user data is stored, sold, shared, or transferred to any third party.
